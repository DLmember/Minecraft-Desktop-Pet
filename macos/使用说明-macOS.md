# Minecraft桌宠 2.4.10 — macOS 修订 3

适用：macOS 12 Monterey 及以上；Apple Silicon / Intel 通用二进制。

## 打开应用

将 Minecraft桌宠.app 拖入“应用程序”后打开，也可以在当前目录直接打开。
这是从 DLmember/Minecraft-Desktop-Pet 提交 afb06a7b18a040ab586f5ef247d13997bdb799b8 移植的本地构建，使用临时本机签名，未经过 Apple 公证。如 macOS 阻止运行，请在“系统设置 → 隐私与安全性”中对本应用选择“仍要打开”。不需要关闭系统安全功能。

## 基本操作

- 点击屏幕顶部菜单栏的方块图标 →“打开控制台”。
- 首次启动默认开启完全鼠标穿透。要拖动桌宠，请在菜单中取消穿透。
- 取消穿透后：拖动可移动；双击或右键可打开控制台。
- 菜单栏可控制置顶、穿透、隐藏、重新居中、导入皮肤、退出。
- 控制台提供站立/坐下/自定义姿态、经典/纤细手臂、缩放、30–240 FPS、鼠标跟随、头部参数、身体旋转、分开编辑的自定义站姿/坐姿、打字动作及主手选择。
- 透明桌宠窗口支持多个桌面与全屏辅助显示；静止时暂停模型重绘。
- 关闭控制台不退出程序；请从菜单栏选择“退出 Minecraft桌宠”。

## 输入权限与快速聊天

控制台顶部固定显示四个按钮：**申请输入监控、申请辅助功能、重新检测、重启应用**，无须滚动。菜单栏也有直接申请入口。首次缺少权限会自动打开控制台。

1. 点击“申请输入监控”，应用调用系统授权请求并定位到权限页。请开启 Minecraft桌宠；系统权限开关需要由用户亲自确认。
2. 返回应用后会每秒检测并自动重连。如果系统要求退出重新打开，点击“重启应用”。
3. 在“输入与聊天”页开启 **hyp 快速队伍聊天**。它需要“辅助功能”权限；勾选时会立即申请，也可点击顶部“申请辅助功能”。
4. 在同页测试框输入半角 #，应变为 /p chat （末尾有一个空格），不会按回车、不会自动发送。

快速聊天默认关闭，与原 Windows 版保持一致。开启时对当前输入窗口生效。长按 # 只替换一次，匹配的松键不会泄漏；Command / Control 快捷键不被替换。根据键盘布局判断实际字符，兼容 Shift+3、独立井号键及 Mac UK Option+3。使用标记区分自己的模拟事件，不产生重复替换或额外敲击动作；不读写剪贴板、不模拟松开用户物理按住的修饰键。

输入监控驱动坐姿敲键和站姿 Shift 潜行，不保存文字、不上传按键；快速聊天仅在明确开启后过滤半角井号。系统安全输入模式可能暂时阻止监听。动作键位按 ANSI 物理位置映射。

如果旧的临时签名版本已授权，而新版本依然显示待授权，请在系统权限列表中移除旧条目，再用当前应用的申请按钮重新添加。建议从固定位置运行应用，以保持权限定位一致。

## 修订 3 输入修复

- 校验系统实际开放的 keyDown/keyUp 事件；只有修饰键的监听不再显示为已连接。
- 聊天拦截不可用时回退只读键盘监听；后台重试不会反复中断已工作的键盘动作。
- “重新检测”强制重建监听，授权变化自动触发恢复。
- 井号替换同步复用原事件的目标路由，移除不可靠的前台进程判断。
- 输入页显示真实按下、松开、替换次数和安全输入状态；不保存输入文字。
- 本地临时签名更新后可能需要重新添加权限。请添加实际运行的应用，避免混淆 /Applications 中的旧版本。

## 皮肤

可导入 PNG：64×64、旧版 64×32，以及等比例高清皮肤（最大 1024×1024、8 MB）。也可主动输入正版 Java 版用户名/UUID，从 Mojang 官方资料及纹理服务下载。网络错误显示在控制台内。

## 设置

自动保存到：~/Library/Application Support/MinecraftDesktopPet-macOS/

设置及备份保存在此处，导入皮肤另存为 skin.png。应用包含“打开设置文件夹”和“恢复默认设置”按钮。此目录独立于其他旧版 Mac 移植应用，避免覆盖其设置。

## 与 Windows 版的差异

- 窗口、菜单栏、设置、全局输入及网络层使用原生 AppKit / macOS 接口。
- 角色、皮肤、动画、精确敲键、挥手、潜行和姿态计算直接使用原项目 Rust 渲染器。
- hyp 快速队伍聊天已使用 macOS 事件过滤实现，需要辅助功能权限。
- macOS 12 的最低版本已写入构建目标；实际运行验证在本机 Apple Silicon / macOS 27 完成，x86_64 版本也已通过 Rosetta 启动验证，尚未在 Intel 实机验证。

## 从源码重建

需要 Xcode Command Line Tools、Swift 和 Rust stable：

    rustup target add aarch64-apple-darwin x86_64-apple-darwin
    scripts/build-macos.sh /absolute/path/to/output

运行原始渲染、配置与桥接测试：

    cargo test --manifest-path native/Cargo.toml --lib --locked
    "Minecraft桌宠.app/Contents/MacOS/MinecraftPet" --self-test-input

应用内回归可在独立临时目录运行，不修改正式设置：

    "Minecraft桌宠.app/Contents/MacOS/MinecraftPet" --self-test-ui --data-dir /tmp/minecraft-pet-ui-test
