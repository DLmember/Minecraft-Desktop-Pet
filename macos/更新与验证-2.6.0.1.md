# v2.6.0.1 · macOS 专版

**本次发布不提供 Windows 版。** Windows 用户可继续使用 [Windows v2.6](https://github.com/DLmember/Minecraft-Desktop-Pet/releases/tag/v2.6)。

- 跟随、呼吸和动作按桌宠所在屏幕的刷新率绘制。Apple Silicon 优先使用 Metal 和可复用的共享帧缓冲区。
- 移除控制台「大小」与「打字压低」之间的空行，内容区从 646 × 694 缩至 638 × 618 点。
- 浮字和音效按需加载。直播采集和部分特效使用软件绘制，回到 Metal 后回收闲置的软件绘制缓冲区。
- 在 M1、60 Hz、Q 版 65% 缩放的持续跟随测试中，本次渲染路径折算约占整机 CPU 时间 0.82%。实际表现取决于配置与使用场景。
- 在同台机器的独立窗口测试中，桌宠进程的物理内存中位数为单独显示时 18.5 MiB、首次打开控制台时 41.7 MiB、关窗后采样期间 38.6 MiB。以上均为场景测试值。

M 系列芯片选 Apple Silicon（macOS 12+），Intel Mac 选 Intel（macOS 13+），跨架构部署选 Universal。下载后解压，退出旧桌宠，再打开新版应用。安装包采用本地临时签名。
