# v2.6.0.2 · macOS 专版

**本次发布不提供 Windows 版。** Windows 用户可继续使用 [Windows v2.6](https://github.com/DLmember/Minecraft-Desktop-Pet/releases/tag/v2.6)。

## v2.6.0.2 更新

- 修复打开、关闭控制台后桌宠长期多占约 20 MiB 内存的问题。设置窗口在同一个应用包的临时进程内显示，关闭窗口会退出该进程。桌宠继续运行，设置实时生效。
- 「常规」「视线与角度」「其他设置」使用原生圆角按钮，支持 Apple Silicon 和 Intel Mac。
- 改用一个 Universal DMG 安装包。退出旧桌宠，双击 DMG，把「Minecraft桌宠」拖到「Applications」，然后从「应用程序」打开。

## 包含 v2.6.0.1 的更新

- 跟随、呼吸和动作按桌宠所在屏幕的刷新率绘制。Apple Silicon 优先使用 Metal 和可复用的共享帧缓冲区。
- 移除控制台「大小」与「打字压低」之间的空行，内容区从 646 × 694 缩至 638 × 618 点。
- 浮字和音效按需加载。直播采集和部分特效使用软件绘制，回到 Metal 后回收闲置的软件绘制缓冲区。
- 在 M1、60 Hz、Q 版 65% 缩放的持续跟随测试中，本次渲染路径折算约占整机 CPU 时间 0.82%。实际表现取决于配置与使用场景。
- v2.6.0.1 在同台机器的独立窗口测试中，桌宠进程的物理内存中位数为单独显示时 18.5 MiB、首次打开控制台时 41.7 MiB、关窗后采样期间 38.6 MiB。以上均为场景测试值。

系统要求：Apple Silicon 需 macOS 12 或更高，Intel 需 macOS 13 或更高。应用采用本地临时签名。
