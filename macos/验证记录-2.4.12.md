## 本地补齐

- 披风从同一 Mojang profile 与皮肤一起下载、校验、保存；重启恢复；显示开关。
- 任一下载或纹理校验失败保留原外观；账号无披风或导入本地皮肤清除之前的披风关联。
- 原生“启动与性能”页：当前用户 LaunchAgent、登录延迟 0/5/15/30/60/120 秒、五档主线程/渲染线程 QoS。

- QoS 是 macOS 调度请求，不是 Windows 进程优先级的完全等价实现。
- UI、网络 User-Agent、诊断、Info.plist 和包名使用一致的版本来源。
- 保留既有键盘、快速聊天、单次鼠标挥臂和保存时不中断动画的逻辑。

## 代码检查与修复

1. 披风解码前增加尺寸限制：最大 1024×512、2 MB，避免小压缩文件导致过大解码分配。
2. 上游披风以负 U 偏移定位图案，其他面会采样到图像左边缘。改为标准完整纹理展开与模型朝向旋转，增加六面 UV 回归。
3. Mac 皮肤/披风先共同校验，再用独立一代文件保存，避免新旧账号外观混用；只清理本导入器创建的文件，不删除用户源文件。
4. 官方纹理 URL 限制 HTTPS 官方域名/合法路径；兼容服务返回的 HTTP 地址并升级到 HTTPS；跨域重定向在发起跳转请求前拒绝。
5. 登录启动使用 plist 参数数组，不拼接 shell 命令，含空格、中文、引号等路径经过测试。注册不启动第二实例，不使用 KeepAlive。
6. Windows CI 显式指定交叉编译 windres/linker；Windows ZIP 补齐 THIRD_PARTY_NOTICES 与依赖许可证。未实际运行远端 CI。
7. 分发二进制重映射源路径并剥离链接调试符号；本机 home 路径扫描结果为 0。
