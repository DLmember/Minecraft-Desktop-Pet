# macOS v2.6 — 基于 CPU 优化版跟进主版本

日期：2026-11-09。本地候选版；未提交、推送或发布。

## 来源与合并

- Release：[Minecraft桌宠 v2.6](https://github.com/DLmember/Minecraft-Desktop-Pet/releases/tag/v2.6)。代码基准：`c71ac8e9f5d5764b91d4733858c37c90aec75a26`。
- 在本地 CPU 优化源码上三方合并共享 Rust 改动，保留眨眼休眠、15 FPS 纯呼吸、动态画布、扫描线优化、Mac 键名、权限引导和输入恢复。
- Windows 新增模块、界面、配置新增字段和资源来自正式版本，不跟进 AI 或特殊分支。Windows 入口及新增模块与该 tag 保持一致；保留 macOS 已移除 startupPriority 的行为。
- 版本统一读取 `native/Cargo.toml`，本版为 **2.6.0**。Intel macOS 13+，Apple Silicon macOS 12+；仍输出 universal 和两个单芯片 ZIP。

## 功能

- 第三页改名“其他设置”，加入装饰与采集窗口；保留自定义姿态和键盘样式/色号。常规页移除 Windows v2.6 已删除的外层显示、披风显示开关和冗余提示；锁定双击移入桌面行。macOS 的帧率设置保留并移至“其他设置”，用于性能控制。
- 邦友的酒：复用上游 `wine_transform`，130 BPM 压缩/旋转与视线限制。只是按时间轴运动，没有歌曲识别、音乐文件或自动播放器控制。开启时必须持续刷新，不能套用低频呼吸预算。
- 自选披风：复用全部内置披风和目录，12 项/页，支持跟随账号、无披风、内置选择及持久化。仅当前页保留缩略图。账号披风文件保持独立。
- 装饰：兔耳、猫耳、爱心、美西螈、棒棒糖，复用上游模型/纹理与测试；静止装饰不强制持续渲染。
- 直播采集：普通不透明 NSWindow + 绿色底色；与桌宠共享不可变 CGImage，没有第二个 Rust 渲染器/计时器。关闭释放图像，支持前后放置与窗口缩放。桌宠隐藏时不额外绘制。
- 官方皮肤模型信息随导入保存，恢复内置清除该信息；不改写旧账号披风。
- 披风、装饰来源说明和资源许可随应用打包，不删除许可证缩小体积。

## 验证与边界

- Rust 双架构：107 项通过，4 项原有忽略；覆盖旧 CPU 优化、v2.6 动作周期、装饰渲染、披风目录/有效性/选择与恢复。
- Swift 双架构：207 项输入/平台断言；UI、重启、登录启动回归通过。UI 增加披风分页/选择/关闭、六种装饰切换、邦友动作保存/持续刷新、采集窗口共享帧/关闭与放置检查。
- Intel 在 Apple Silicon 上通过 Rosetta 执行，不代表实体 Intel 性能或所有旧系统兼容性。
- 未操作音乐播放器；歌曲对拍、OBS/直播姬实际捕获及长时间直播由用户试用，不能把生成绿幕截图等同于 OBS 验证。
- README 未改，正式安装及 GitHub Release 未替换。

## CPU 与产物

Apple M1 / macOS 27.0，使用此前 CPU 基准脚本，三次测量中位数（预热 3 秒、计时 8 秒，合成皮肤，关闭播放器与全局输入）：

| 场景 | CPU | 实际绘制 FPS |
|---|---:|---:|
| 65% 大小，仅呼吸，设置 120 FPS | 4.08% | 15.0 |
| 100% 大小，仅呼吸，设置 120 FPS | 5.68% | 15.0 |
| 静止 | 0.47% | 0 |
| 仅眨眼 | 1.40% | 6.0（动画间隔不绘制） |

此测量不包括开启邦友动作、装饰和采集窗口后的负载，不保证所有机型相同。新动作持续运动时恢复交互绘制预算，不能声称仍只有呼吸占用。原始结果位于本地 `release/v2.6-cpu-benchmark/results.json`。

本地候选放在 `release/v2.6-cpu/`。单芯片应用文件字节合计约 Apple Silicon 4.08 MB / Intel 4.21 MB（小于 5 MB），universal 约 6.17 MB；通用包按要求保留。
