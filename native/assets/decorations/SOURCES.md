# Decoration sources

- Axolotl: Mojang/Microsoft Minecraft artwork. Geometry verified against Java 26.2 AdultAxolotlModel, adapted to a flat resting pose; original Lucy texture from the installed game. Earlier geometry reference: Mojang/bedrock-samples. Creature attachment height uses posed bounds.
- Lollipop: original procedural pixel artwork for this desktop pet.
- Blub and its assets were removed in preview13 at the user's request. Earlier source snapshots retain their original provenance and license.

preview13 fixes the axolotl tail and dorsal fin by using the same texture on both sides of zero-width planes, mirrored to preserve the physical pattern. Ordinary solid cuboids keep their existing texture mapping.
